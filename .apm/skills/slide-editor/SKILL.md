# スライドを編集する（slide-editor）

閲覧用HTMLを **iframe に載せて外から操作する枠**。意匠は持たない（中の HTML が自分の意匠層を持っている）。
編集しても元のファイルは書き換わらず、**保存したときだけ**原稿と意匠属性が差し戻される。

## 使い方

1. `assets/frame.html` をブラウザで開く
2. 「開く」で閲覧用HTMLを選ぶ（ドラッグ＆ドロップでも可）
3. 直す、見せる
4. 「保存」で元のファイルへ書き戻す

File System Access API が使えるブラウザ（Chrome / Edge）では**元のファイルを直接上書き**する。
使えない場合はダウンロードになるので、元のファイルと差し替える。

## 操作

| ボタン | キー | 動き |
|---|---|---|
| 開く | — | 閲覧用HTMLを読み込む。ドロップでも同じ |
| 保存 | `⌘S` / `Ctrl+S` | 原稿と意匠属性を元のファイルへ差し戻す |
| 編集 | `E` | 文字を直接直せるようにする。もう一度押すと解除 |
| マスター | — | report → jtc → mono の順に切り替える |
| テーマ | — | light → dark → auto の順に切り替える |
| 発表 | `F` | 全画面で 1 枚ずつ表示する。`Esc` で戻る |
| （左の一覧） | `←` `→` | スライドを移動する |

## 書き戻す範囲

保存時に差し替えるのは 2 か所だけ。

- `<div class="dm-deck" id="dmDeck">` の中身（原稿）
- `<html>` の `data-master` / `data-theme`

意匠層（`<style id="deck-style">`）と束ね層（`<script id="deck-layout">`）、その他のファイル内容はそのまま残る。
束ね層が実行時に作る `.dm-holder` やページ番号、編集用の属性は取り除いてから書き戻す。
読み込んで何も触らずに保存すれば、**元のファイルと同一の内容**になる。

## できること・できないこと

できるのは、文字の直し、マスターとテーマの切り替え、スライドの移動、発表表示。

**ブロックの追加・削除・並べ替え、レイアウトの変更、工程表の組み立ては slide-deck の担当。**
構造を変えたいときは原稿を書き換える側で作業する。この枠は「書き上がったものに人が手を入れる」ためのもの。

## エージェントから操作する

自動テストやエージェントからは `window.SlideEditor` を使う。

| 関数 | 用途 |
|---|---|
| `load(text, name)` | 閲覧用HTMLのテキストを読み込む |
| `build()` | 現在の状態を書き戻したテキストを返す（保存はしない） |
| `go(i)` | i 枚目へ移動 |
| `setEditing(on)` | 編集モードの切り替え |
| `slideCount()` | スライド枚数 |

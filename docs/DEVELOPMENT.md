# 開発ルール

agent-kit 自身の開発ルールと運用の決めごと。

- 作業の手順

| 作業 | 手順 |
|---|---|
| 自作スキル・ルールを直す | ここで編集 → 任意のプロジェクトで `apm install /abs/path/agent-kit` して確認 → タグを打つ。プロジェクト側は次の `apm install --update` で追随する |
| 市中スキルを足す | `dependencies.apm` に `owner/repo/path#<sha>` を追加。同名スキルが無いことを確認(同名は先勝ちで無視される) |
| 市中スキルを追従する | `apm install --update --dry-run` で差分を見て SHA を更新 → タグ |

- 運用ルール
  - 版はセマンティックバージョンのタグ。スキル名の変更・削除やルールの適用範囲拡大はメジャーを上げる。
  - プロジェクト側はレンジ(`#^<major>.<minor>.<patch>`)で参照する。キットのタグ運用と組み合わせ、プロジェクトの `apm.yml` は据え置く。
  - 市中依存はコミット SHA でピンする。ブランチ参照は使わない。
  - 自作スキル・ルールの編集はこのリポジトリだけで行う。プロジェクト側の配置物は次の `apm install` で上書きされる。
